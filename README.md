# Kenny He — Event Photography

A minimalist, photo-first portfolio site for an event photographer, built with [Astro](https://astro.build). Bilingual (English/Spanish) with Astro's built-in i18n routing, content collections for event write-ups, and a hand-rolled vanilla-JS lightbox.

Deployed to GitHub Pages at **https://kennyhc.github.io/event-photographer**.

## Running locally

```bash
npm install
npm run dev
```

The dev server runs at `http://localhost:4321/event-photographer/` (the `/event-photographer/` base path is part of every URL, matching production).

Other scripts:

```bash
npm run build     # type-checks nothing itself, but builds the static site to dist/
npm run preview   # serve the built dist/ locally
npx astro check   # TypeScript/Astro diagnostics
```

## Adding real photos

Placeholder JPEGs were generated by `scripts/make-placeholders.mjs` (muted gradient tones, mixed portrait/landscape) so the site builds and looks reasonable before real photos exist. **Delete them and drop in real photos:**

1. Delete the files in `src/assets/events/wedding-bali/`, `src/assets/events/baptism/`, and `src/assets/about/portrait.jpg`.
2. Add your own JPEGs to `src/assets/events/<slug>/`. Photos are picked up automatically (sorted by filename) — no code changes needed.
3. Name one file `cover.jpg` (or `.jpeg`/`.png`/`.webp`) per event folder to control which photo is used as the hero/card image. If there's no `cover.*`, the first file (alphabetically) is used instead.
4. The editorial gallery on each event's story page shows every photo in the folder, up to 30 per event (`getShowcase` in `src/lib/images.ts` — raise the `max` there if you want more).
5. Replace `src/assets/about/portrait.jpg` with a real portrait (any aspect ratio close to 4:5 works best).

You can re-run `node scripts/make-placeholders.mjs` at any time to regenerate placeholders (it overwrites existing files of the same name).

## Adding or editing events

Each event is a markdown file in `src/content/events/en/<slug>.md` and the matching `src/content/events/es/<slug>.md`, sharing the same `<slug>` and frontmatter shape:

```md
---
title: "An Intimate Baptism"
location: "Spain"
date: "2026"
summary: "A quiet morning in a small parish church..."
order: 2
testimonial:
  quote: "..."
  author: "..."
---

Body copy in Markdown.
```

`testimonial` is optional — omit it to hide that section on the story page. `order` controls sort order on the home page and work index. To add a new event, create both the `en` and `es` markdown files with a new matching slug, and a matching `src/assets/events/<slug>/` photo folder.

UI strings (nav labels, button text, etc.) live in `src/i18n/ui.ts`.

## Deploying to GitHub Pages

This repo includes `.github/workflows/deploy.yml`, which builds and deploys the site on every push to `main` (and via manual `workflow_dispatch`), using `withastro/action` + `actions/deploy-pages`.

To enable it on GitHub:

1. Push this repo to `KennyHc/event-photographer` on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **GitHub Actions**.
4. Push to `main` (or run the workflow manually from the Actions tab) — the site will publish to `https://kennyhc.github.io/event-photographer`.

## Tech

- Astro (static output), TypeScript, plain scoped CSS — no UI framework, no Tailwind.
- `astro:content` collections (glob loader) for event write-ups, split by locale.
- Astro's built-in i18n routing (`en` at `/`, `es` at `/es/`).
- `astro:assets` `<Image>` for responsive, lazy-loaded, webp-optimized images.
- A small vanilla-JS module (`src/scripts/site.ts`) for the lightbox, mobile nav, scroll fade-ins, and the transparent-over-hero header — no dependencies.
- `@fontsource/fraunces` (headings) and `@fontsource/inter` (body/UI), self-hosted.
